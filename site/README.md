# AI Monitor landing page

A static landing page with no build step or package dependencies.

Preview from the repository root:

```sh
python3 -m http.server 4173 --directory site --bind 127.0.0.1
```

Open http://127.0.0.1:4173. Deploy the contents of `site/` to any static web host.

The product preview uses illustrative data. Its Used / Remaining control is interactive. Download links target version 0.1.12; update all three `.download` links when publishing a new release. Google Fonts supplies DM Sans and Manrope, with local sans-serif fallbacks.
