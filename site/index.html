A few things to know

Good questions.

Which Macs are supported?

AI Monitor requires macOS 14 or later and runs on both Apple Silicon and Intel Macs. The download is signed with Developer ID and notarized by Apple.

Does this track API spending?

Claude and Codex show subscription usage. Codex connects through ChatGPT, not the OpenAI API. OpenCode Go shows subscription quotas. With the advanced console connection, OpenCode Zen shows its balance and spending over the last 30 days.

How often does usage refresh?

Selected Codex and OpenCode accounts refresh once per minute. Claude checks no more than once every five minutes and backs off if throttled. Other accounts refresh when you open the popover or refresh manually.

Where does my data go?

Credentials are stored in macOS Keychain. Account names and settings stay on your Mac, and usage requests go directly to each provider. There is no backend or analytics.

Can I connect more than one account?

Yes, including multiple accounts from the same provider. Each account has its own name and menu bar settings. When signing in, select the account you intend to connect in your browser.

What happens when a login expires?

Claude and Codex browser sign-ins renew automatically. Pasted tokens, imported CLI credentials and cookies can't be renewed, so use Reconnect when prompted. Imported CLI credentials are snapshots, and the app never changes the original authentication file.
